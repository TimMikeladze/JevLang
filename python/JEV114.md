# Jev 1.14 Python support

The native Python package supports the portable Jev 1.14 extension. Python 3.9+;
no Node, Racket, SDK or third-party runtime dependency. Calls default to
`jev-1.14.0`. An explicit model overrides the default; aliases remain aliases,
with a 300-second default cache lifetime. No live model accuracy claim is made.

Run the offline example from the package directory:

```sh
PYTHONPATH=. python3 examples/image_localization.py
```

## Images and Box

`box(id, instructions)` declares a normalized rectangle. Its `value()`, `top()`,
`bottom()`, `left()`, `right()`, `confidence()` and `has_confidence()` expressions
work offline. Coordinates must satisfy `0 <= left < right <= 1` and
`0 <= top < bottom <= 1`. Confidence may be null or omitted; null trips a
confidence gate. Box supports confidence gates only. Use a presence Noul before
reading a rectangle: Box cannot answer whether an object exists.

Create a portable descriptor with `image_asset(bytes, format='png')`, or supply
`{'type':'image', 'format':'png', 'data_base64':'...'}`. JPEG (`jpg`/`jpeg`) and
non-animated PNG are supported; each dimension must be 280–1568 pixels, each
image <=16 MiB, upload/expanded request <=32 MiB. Validation checks the encoded
container, dimensions and structure; it is not a pixel decoder.

Declare `typesafe={'experimental': {'images': True}}` on the policy. Supply an
`assets` reference map through `policy.evaluate(input, assets=...)` or statically
in `typesafe.assets`. References appear in state strings, question instructions,
or criteria. Unused assets and duplicate static/runtime references are errors.
References survive redaction and cannot be cut in half by string caps.
Images and Box require the explicit image flag; Jev 1.13 rejects Box.

Portable policy fields remain camelCase. Python calls also accept
`asset_transport='json'` (default multipart), `compression='gzip'`,
`experimental={'longContext': True}`, `timeout_seconds=10`, partial `retry`,
`headers` and an `asyncio.Event` as `cancel_event`. Authentication and generated
headers cannot be overridden through per-call headers. Standard context limits
are 32,000 tokens for state plus one question and 64,000 for all questions;
explicit long context raises both to 262,000. Estimates use ~4 characters/token.

Auto compression uses zstd for bodies >=1 KiB when the runtime provides it,
otherwise uncompressed bytes. Gzip always works. Explicit zstd fails when
unavailable. The standard-library [zstd module](https://docs.python.org/3/library/compression.zstd.html)
is available starting with Python 3.14; its window is limited to 8 MiB here.
Native asyncio HTTP supports task/event cancellation through request reads,
retry waits and pacing. No HTTP/2 or SDK-specific response classes are required.

## Cache, recording and accounting

Use `await evaluate_with_provider(policy, input, assets=..., cache={})` in async
code. `Policy.evaluate(...)` and `Policy.record(...)` are synchronous and must
run outside an active event loop. Reuse the same dictionary between calls.
Cache keys include image contents/placements, questions, effective target and
experimental flags. Renaming a reference preserves identity. Concurrent rows
share an in-flight call. Failed/fallback calls do not populate a primary-target
entry. `cache_only=True` performs no discovery or network request; use
`cache_max_age_seconds` to override expiry. Completed cache entries contain
provider objects and are intended for this process, not direct JSON persistence.

Image recording creates fixture version 4 with digests, dimensions, placements,
flags and provenance. `include_assets=True` embeds portable image bytes for
self-contained replay; default records omit them. Text fixtures remain v3.
Replay reports `decisionVerified` separately from `assetsVerified`; pass assets
or embed them to verify image contents. A changed image fails verification.

Image token estimates and total cost are unknown until usage is reported.
Null/missing input usage produces a null cost. Batch reports retain known token
subtotals and expose `usage_complete`/`unreported_calls`; pipelines preserve
nullable token totals. Numeric Box confidences enter monitoring histograms;
Box rectangles are excluded from categorical calibration.

## CLI and servers

```sh
python3 -m jevlang models
python3 -m jevlang evaluate policy.json input.json options.json
python3 -m jevlang record policy.json input.json options.json
python3 -m jevlang batch policy.json rows.json options.json
```

Options JSON carries portable assets/experimental/compression fields and model
selection. Batch uses the same options for every input. Model listing returns
the API's `models` array, with `name`, `description` and `release_date` fields.

HTTP `/evaluate` and `/dispatch`, and the MCP evaluate tool, accept JSON-safe
assets and flags. The server operator enables experimental features via policy
settings or `experimental=` on `start_server`/`policy_mcp_server`. Remote callers
cannot enable a disabled feature or override upstream connection/model settings.
For these requests, supply `evaluate(state, options)` that forwards
`**options` into `evaluate_with_provider`. Legacy one-argument callbacks remain
supported for text-only requests. If the requested HTTP port is busy, the server
tries subsequent ports on Linux and macOS without stopping the existing process. Policy metadata carries image manifests,
never base64 bytes; there is no binary MCP upload endpoint.

## Verification

`tests/fixtures/jev114-shared.json` was generated by the standalone JavaScript
engine. Native Python tests compare full decisions, manifests, content identity,
policy identity and cache keys, including Unicode keys and null confidence.
JPEG samples cover baseline/progressive encoding. Tests run without API keys.
Racket-only oracle tests skip when Racket is absent; existing text differential
checks still run against the monorepo JavaScript reference when available.
